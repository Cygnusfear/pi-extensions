# context7

Fetch up-to-date library documentation and code examples via [Context7](https://context7.com).

Calls the Context7 MCP server directly over HTTP — no local MCP setup needed.

## Tools

| Tool | Description |
|------|-------------|
| `context7_resolve` | Resolve a library name to a Context7 library ID |
| `context7_docs` | Fetch documentation for a resolved library ID |

## Setup

Works without configuration. Set `CONTEXT7_API_KEY` for higher rate limits (free at [context7.com/dashboard](https://context7.com/dashboard)).
